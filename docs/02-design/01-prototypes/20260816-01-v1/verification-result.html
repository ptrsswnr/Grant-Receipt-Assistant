ตัวอย่างที่ 1: สถานะ "ต้องแก้ไข"

🧾
฿4,500.00
12/08/2568 · ค่าวัสดุ · ร้านวัสดุก่อสร้าง ใจดี
ต้องแก้ไข

ใบเสร็จนี้มียอดเงิน 4,500 บาท ซึ่งเกินวงเงินสูงสุดที่กำหนดไว้สำหรับหมวด "ค่าวัสดุ" (ไม่เกิน 3,000 บาทต่อรายการ) วิธีแก้ไข: กรุณาแยกใบเสร็จตามรายการย่อย หรือเลือกหมวดค่าใช้จ่ายให้ตรง กับประเภทของรายการนี้มากขึ้น แล้วส่งเข้าตรวจใหม่อีกครั้ง

📎 อ้างอิง: ระเบียบการเบิกจ่ายค่าวัสดุ ข้อ 4.2 (เวอร์ชันระเบียบ 2568.1, นำเข้าโดย Admin เมื่อ 01/08/2568)
อัปโหลดใบเสร็จใหม่แทน แก้ไขข้อมูลและส่งตรวจซ้ำ

FR-07 — แก้ไข/อัปโหลดใบเสร็จใหม่แทนใบเดิม แล้ววนกลับไปตรวจกับ Rule Engine ซ้ำจนกว่าจะผ่าน

฿1,200.00
10/08/2568 · ค่าเดินทาง · บริษัท ขนส่งด่วน จำกัด
ผ่าน

ใบเสร็จนี้ผ่านเกณฑ์ทุกข้อ ยอดเงินไม่เกินวงเงินสูงสุดของหมวด "ค่าเดินทาง" และมีข้อมูลครบถ้วนตามที่ระเบียบ กำหนด พร้อมสำหรับนำไปรวมในรายงาน Export เพื่อยื่นเจ้าหน้าที่การเงิน

📎 อ้างอิง: ระเบียบการเบิกจ่ายค่าเดินทาง ข้อ 2.1 (เวอร์ชันระเบียบ 2568.1)
ไปที่หน้า Export รายงาน

ตัวอย่างที่ 3: สถานะ "ไม่เข้าเงื่อนไข"

🧾
฿850.00
05/08/2568 · ค่าบันเทิง (ไม่อยู่ในรายการที่อนุญาต) · ร้านอาหารริมทาง
ไม่เข้าเงื่อนไข

หมวดค่าใช้จ่าย "ค่าบันเทิง" ไม่อยู่ในรายการหมวดที่ทุนวิจัยนี้อนุญาตให้เบิกได้ ใบเสร็จนี้จึงไม่สามารถนำไปยื่นเบิกกับทุนนี้ได้ กรุณาตรวจสอบว่าเลือกหมวดถูกต้องหรือไม่ หากยืนยันว่า เป็นรายการนี้จริง ใบเสร็จนี้จะไม่สามารถนำไปรวมในรายงาน Export ได้

📎 อ้างอิง: ระเบียบรายการหมวดค่าใช้จ่ายที่อนุญาต ข้อ 1.1 (เวอร์ชันระเบียบ 2568.1)
