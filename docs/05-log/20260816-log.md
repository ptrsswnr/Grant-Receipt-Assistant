**คำถามที่ถามผู้ใช้และคำตอบที่ได้** (ถามเป็นข้อความปกติ เนื่องจากเครื่องมือ AskUserQuestion
ไม่ได้ถูกส่งมาให้ใช้ในเซสชันนี้ — ทุกคำถามเสนอตัวเลือกอย่างน้อย 3 ตัวเลือกพร้อมระบุตัวเลือกที่แนะนำ):

1. ฐานทางกฎหมายในการเก็บ/ประมวลผลข้อมูลใบเสร็จของนักวิจัย (กระทบว่าต้องมี UI ขอ consent หรือไม่)

   และผลกระทบต่อกระบวนการตรวจใบเสร็จ) ผลกระทบเรื่องพฤติกรรมระบบเมื่อถอน consent ต่อข้อมูลที่เคย
   ประมวลผลไปแล้ว ยังไม่มีคำตอบชัดเจน จึงบันทึกเป็น **open point** ในเอกสาร (หัวข้อ 2.3, 6 ของ

2. ต้องมีฟีเจอร์ลบข้อมูลใบเสร็จของตัวเองด้วยตนเองผ่าน UI ใน MVP นี้หรือไม่

   นี้เลย** — เพิ่ม FR-18 พร้อมเงื่อนไขจำกัดเฉพาะใบเสร็จที่ยังไม่ถูก export ส่งเจ้าหน้าที่การเงิน

   บันทึกเป็น open point ในเอกสารเช่นกัน (ต้องทบทวนอีกครั้งเมื่อทราบตัวเลข retention จริง)
3. OCR/LLM vendor อยู่ในไทยหรือต่างประเทศ (กระทบ cross-border transfer requirement)
   → ผู้ใช้**ยืนยันตามตัวเลือกที่แนะนำ**: ยังไม่ตัดสินใจ (TBD) เขียนเป็น NFR-08 แบบมีเงื่อนไข

   stack ใดๆ สอดคล้องกับกฎ "ห้ามสมมติ tech stack" ของโปรเจกต์

ข้อ 3, 5, 6, 7 ของ gap analysis เดิม (DPA กับผู้ให้บริการภายนอก, data breach notification,
