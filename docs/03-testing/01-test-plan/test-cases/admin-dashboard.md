> **สถานะ: รันไม่ได้ (blocked — ยังไม่ได้สร้าง FR-35)** test case ชุดนี้เป็นเกณฑ์รับมอบ ใช้เมื่อสร้างแล้ว ทดสอบด้วยมือทั้งหมดบน `fund-sources.html`/`projects.html`
> ใช้แหล่งทุนทดสอบที่สร้างเองซึ่งมีเวอร์ชันกฎ ≥ 1 กฎ ≥ 2 และมีโครงการของนักวิจัย A ผูกอยู่พร้อมใบเสร็จที่ตรวจแล้ว ≥ 1 ใบ
> **จุดเปิดที่ spec ระบุไว้แล้ว:** พฤติกรรมของใบเสร็จใหม่ในโครงการที่ผูกกับแหล่งทุนที่ปิดใช้งานยังไม่ได้กำหนด (TC-22-11 บันทึกไว้เป็นข้อสังเกตเท่านั้น)
