อ้างอิง [[acceptance-criteria#17. อ่านใบเสร็จด้วย AI และ OCR ภาษาไทยในเครื่อง|ฟีเจอร์ที่ 17]] และ
[[user-journey#Journey 1: นักวิจัยอัปโหลดใบเสร็จและตรวจสอบผลจนผ่านเกณฑ์|Journey 1]] (ขั้นตอนที่ 9-10)

> **วิธีทดสอบ:** `auto` = test อัตโนมัติ — ตัวสกัดค่าจากข้อความ OCR (`tests/ocr-client.test.js`), ตัวเรียก AI และการเลือกผู้ให้บริการ (`tests/eval.test.js` กลุ่ม AiClient),
> proxy (`tests/proxy.test.js`) — `manual` = ต้องทดสอบด้วยมือ โดยเฉพาะการอ่านภาพจริงผ่าน AI, การทำงานของบริการ OCR ภาษาไทยในเครื่อง (Python/ONNX),
> การแปลง PDF หน้าแรกในเบราว์เซอร์ และ **proxy หลัง deploy จริง** (ปัจจุบันยังไม่ได้ deploy — TC-17-12 รันไม่ได้จนกว่าจะ deploy)
> ห้ามใช้ใบเสร็จจริงที่มีข้อมูลส่วนบุคคลในการทดสอบกับผู้ให้บริการภายนอก ใช้ใบเสร็จตัวอย่างที่สร้างขึ้น และคีย์ OpenRouter ในโปรเจกต์เป็นของคลาสเท่านั้น
